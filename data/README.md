# Data

The full notebook downloads adjusted prices for nine Select Sector SPDR ETFs and SPY from Yahoo Finance, and DGS3MO, DGS10, T10Y3M and VIXCLS from FRED. Raw downloads are not committed. The notebook records the retrieval window and writes audit tables to the results workbook.

Do not commit credentials, cookies or proprietary data. Review third-party data licences before redistribution.
